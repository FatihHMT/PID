Company format

A format holds your company details for the title block, plus default general notes, pipe classes and drawing settings for new projects. Formats are .md files in PID/Formats.
GitHub storage

Projects and company formats are saved as Markdown files in a GitHub repository, in this structure:
PID/Projects/…md  and  PID/Formats/…md
Missing folders are created for you. Use a private repository and a fine-grained token with Contents: read and write on that repository only. The token is kept in this browser only.
